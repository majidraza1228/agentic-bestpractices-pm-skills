# pm-ai-adoption

Enterprise AI adoption skills for product managers accountable for rolling out and governing AI tools — GitHub Copilot, Microsoft 365 Copilot, Claude, and others.

## Skills

| Skill | Description |
|-------|-------------|
| `ai-adoption-strategy` | Phased rollout framework: pilot design, stakeholder alignment, change management, and tool-specific guidance for Copilot, M365, and Claude |
| `ai-token-optimization` | Cut AI token costs without losing quality — prompt efficiency, context management, model selection, and team-level budgeting |
| `ai-safety-governance` | Safe AI use policies, data classification, DLP controls, incident response, and compliance for enterprise AI rollouts |
| `ai-success-metrics` | KPIs and measurement framework for AI adoption — breadth, quality, productivity impact, ROI calculation, and OKR templates |
| `claude-routines` | Design Claude Routines and Cowork Scheduled Tasks — surface selection, prompt formula, stateless memory pattern, failure modes |
| `managed-agents-design` | Specify and hand off Claude Managed Agents for team-scale automation — agent spec, engineer handoff checklist, guardrails |
| `jira-workflow` | Use Claude to update Jira tickets, track task status via Routines, and generate meeting-ready reports from Jira board data |
| `pm-project-dual-role` | Guidance for PMs carrying both product and project management — how to split work, automate delivery tasks, and protect strategic PM time |

## Commands

| Command | What it does |
|---------|-------------|
| `/plan-ai-rollout` | Build a complete rollout plan: pilot, governance, training, and success metrics |
| `/audit-ai-usage` | Audit current AI tool usage for adoption gaps, cost waste, and safety issues |
| `/build-routine` | Design a Claude Routine or Cowork Scheduled Task — generates a ready-to-paste prompt and setup checklist |
| `/jira-update` | Write a Jira ticket comment, acceptance criteria, or blocker note from a verbal description |
| `/status-for-meeting` | Generate a meeting-ready status report from Jira data — standup, sprint review, or stakeholder update |

## When to Use This Plugin

- You are a PM or program manager responsible for a Copilot, M365, or Claude rollout
- Your organization has deployed AI tools but adoption is low or uneven
- Leadership is asking for ROI evidence on AI spending
- You need a data classification and acceptable use policy before go-live
- Teams are spending too much on tokens and you need a governance model
- You want to automate recurring PM monitoring work (competitor pricing, meeting briefs, OKR pulse) with Claude Routines
- You need to specify a team-wide Managed Agent and hand it off to engineering
- You need to write Jira updates fast or set up automated Jira tracking
- You are preparing a standup, sprint review, or stakeholder status update
- You carry both PM and project manager responsibilities and need to protect strategic time
